## 💡 주요 기술적 해결 과제 및 회고 (Technical Retrospective)

### 1. 한글(HWP) 서식 복제 이슈
*   **문제**: 웹에서 이쁘게 렌더링된 계획서나 표를 한글 프로그램으로 그냥 복사하면 테두리가 사라지거나 폰트 크기가 어긋남.
*   **해결**: 클립보드에 복사할 때 순수 텍스트 대신 `text/html` 타입을 명시하고 한글이 인식할 수 있는 인라인 CSS 스타일(`border-collapse: collapse; font-family: 'Dotum'; font-size: 13pt;`)을 정교하게 랩핑하여 복제해주는 `copyHtmlForHwp` 파서를 별도 설계하여 사용자 경험을 획기적으로 개선함.

### 2. 프리뷰 모델 레이트 리밋(429) 지연 누적 현상
*   **문제**: 1순위 신규 프리뷰 모델(`gemini-3.1-flash-lite`)이 자주 429 한도 초과를 발생시켰는데, 폴백 체인 때문에 사용자는 요청할 때마다 1순위 타임아웃을 기다린 후 2순위로 넘어가 체감 속도가 3배 이상 느려짐.
*   **해결**: 첫 1회 실패 시 서버와 브라우저 단에서 해당 모델에 **5분 쿨다운 낙인**을 찍어 캐싱하는 '자가 학습형 라우터'를 적용. 결과적으로 부하 시간대에도 지연이 아예 없는 쾌적한 API 전환 속도를 확보함.

### 3. 모바일 터치 해상도에서의 학사일정 조작 피로도
*   **문제**: PC용 주간 시간표는 그리드 형태라 셀 크기가 작아 손가락 터치 시 엉뚱한 셀이 눌림.
*   **해결**: 모바일 미디어 쿼리 활성화 시 과목 선택 팝업의 그리드를 3열로 줄이고 버튼 패딩을 12px 이상 확보하여, 조작 피로도를 줄이고 모바일 중심의 반응형 레이아웃 편의성을 더함.
